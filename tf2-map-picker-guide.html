01 / Getting started

Quick Start

⌨️ Use a slash command

Type /map in a Discord channel where the bot is available. Add mode, season, or beta filters if you want a more specific pool.

/map
/map mode:Payload
/map mode:Payload season:Halloween
/map mode:Payload season:Halloween beta:Exclude Beta Maps

🖱️ Use the interactive picker

Mention @TF2 Random Map Picker in a server channel. Then choose Pick Any Map or open the filter picker.

🎲 Pick Any Map ⚙️ Choose Filters

02 / Main command

🎲 /map

What it does

/map randomly picks one map from the pool created by your selected filters. With no options selected, the bot can choose any non-beta map regardless of mode or season.

What the result shows

  • Map name and game mode
  • TF2 map code
  • Your active filters
  • Number of maps in the matching pool
  • Season when applicable
  • Beta status when applicable

03 / Narrow the pool

🔎 Map Filters

🎮

Mode

Choose a specific game mode, or leave it open to allow any mode.

🎃

Season

Choose Normal, Halloween, or Smissmas. Leaving it open allows maps from any season.

🧪

Beta

Beta maps are excluded by default. You can include them or choose only beta maps.

05 / After a roll

Buttons Under a Map Result

🔄 Reroll

Picks another map using the same filters. When possible, it avoids immediately returning the exact same map.

🎮 Another From This Mode

Picks another map from the current map's game mode while preserving applicable season and beta filters.

🎲 Any Map

Clears the mode and season filters and rolls from the bot's general non-beta map pool.

06 / Utility commands

Other Commands

/mapinfo

Map lookup

Start typing a map name or map code to see matching maps, then view its mode, code, season, and beta status.

/modes

Mode list

Displays the game modes currently available in the map database along with their map counts.

/stats

Database stats

Shows counts for standard maps, beta maps, game modes, Normal maps, Halloween maps, and Smissmas maps.

/recent

Shows up to the 5 most recently picked maps in the current server, newest first. Recent-map history is kept in memory and resets if the bot restarts or redeploys.

/help

In-Discord help

Explains the main map picker features, result buttons, filters, and the interactive mention-based picker.

/support

Support development

Shows information about optional support for the bot and provides a Buy Me a Coffee button.

07 / No slash command required

🖱️ Interactive Map Picker

Mention @TF2 Random Map Picker in a server channel to open the interactive picker. You can immediately roll a normal map or configure the same core filters without typing a slash command.

1

Mention the bot

Send a message containing @TF2 Random Map Picker.

2

Pick or customize

Choose Pick Any Map or press Choose Filters.

3

Choose filters

Select a mode, season, and beta-map setting from the menus.

4

Roll the map

Press Pick Map, or use Reset Filters to return to the defaults.

Mode Season Beta 🎲 Pick Map ↩️ Reset Filters

Slash commands such as /map remain available as another way to use the bot.

08 / Common questions

Troubleshooting

No maps match my filters

Some combinations may have no matching maps. Remove one filter or choose a broader setting.

Why are beta maps not appearing?

Beta maps are excluded by default. Choose Include Beta Maps or Beta Maps Only.

What is the map code?

The map code is TF2's internal identifier, such as pl_upward.

What does Map Pool mean?

Map Pool is the number of maps that matched your filters before the bot randomly chose one.

The bot does not answer a mention

Make sure the bot can view the channel and send messages, then try a fresh selected Discord mention.

I just want something random

Use /map with no filters or mention the bot and press Pick Any Map.

09 / Project notes

About TF2 Random Map Picker

TF2 Random Map Picker was built by Raven as a small Discord utility for people who know they want to play Team Fortress 2 but do not particularly want to decide where.

The bot supports both quick completely-random rolls and increasingly specific map pools, while keeping rerolls and follow-up choices one click away.
