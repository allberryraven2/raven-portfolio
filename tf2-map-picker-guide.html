Quick Start

The fastest way to use TF2 Random Map Picker is with the /map command.

  1. Type /map in a Discord channel where the bot is available.
  2. Optionally choose a game mode, season, and beta-map setting.
  3. Send the command.
  4. The bot randomly selects a map from every map matching your filters.
  5. Use the buttons underneath the result if you want another map.
/map
/map mode:Payload
/map mode:Payload season:Halloween
/map mode:Payload season:Halloween beta:Exclude Beta Maps
map_command.txt □ ─ ×

🎲 /map

The bot's main command. It randomly picks one map from the pool produced by your selected filters.

/map

With no options selected, the bot can choose from any non-beta map regardless of mode or season.

The result shows:

  • Map name
  • Game mode
  • TF2 map code
  • Your active filters
  • How many maps were in the pool
  • Season, when applicable
  • Beta status, when applicable
filters.ini □ ─ ×

🔎 Map Filters

🎮 Mode Choose a specific game mode or leave it blank to allow any mode.
🎃 Season Choose Normal, Halloween, or Smissmas. Leaving it blank allows maps from any season.
🧪 Beta Beta maps are excluded by default. You can instead include beta maps or choose only beta maps.

result_buttons.txt □ ─ ×

Buttons Under a Map Result

🔄 Reroll Picks another map using the same filters from the current roll. When possible, it avoids immediately giving you the exact same map again.
🎮 Another From This Mode Picks another map from the current map's game mode. Applicable season and beta filters are preserved.
🎲 Any Map Clears the mode and season filters and rolls from the bot's general non-beta map pool.
commands.exe □ ─ ×

Other Commands

/mapinfo

Look up a specific TF2 map. Start typing the map's name or map code and Discord will show matching maps. The result shows its game mode, map code, season, and beta status.

/modes

Displays the game modes currently available in the bot's map database, along with their map counts.

/stats

Shows statistics for the map database, including standard maps, beta maps, game modes, Normal maps, Halloween maps, and Smissmas maps.

/help

Displays an in-Discord explanation of the main map picker features and controls.

/support

Shows information about optionally supporting development of the bot and provides a Buy Me a Coffee button.

Troubleshooting

No maps match my filters

Some combinations of mode, season, and beta settings may have no matching maps. Try removing one of your filters or using a broader setting.

Why are beta maps not appearing?

Beta maps are excluded by default. Choose Include Beta Maps or Beta Maps Only when using the beta option.

What is the map code?

The map code is TF2's internal map identifier, such as pl_upward. It is displayed separately from the readable map name.

What does Map Pool mean?

Map Pool is the number of maps that matched your selected filters before the bot randomly chose one.

About TF2 Random Map Picker

TF2 Random Map Picker was built by Raven as a small Discord utility for people who know they want to play Team Fortress 2 but don't particularly want to decide where.

The bot is designed to support both quick completely-random rolls and increasingly specific map pools.
