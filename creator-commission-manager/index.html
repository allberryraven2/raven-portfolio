02 / Server permissions

🔐 Commission Access

The server owner controls who can create and manage commission queues with /commission access. Customer-facing request actions are separate and remain usable even when management access is restricted.

Everyone

Any server member can use commission-management commands.

Owner Only

Only the Discord server owner can use management commands.

Selected Role

Only members with the selected role can manage commissions. The server owner always retains access.

Customers

Customers do not need the creator-management role to submit requests, cancel eligible requests, or confirm delivery.

03 / Organize commission types

📋 Commission Queues

Queue controls

  • Create multiple commission queues
  • Set a name, description, and slot limit
  • Open or close requests
  • Edit existing queue details
  • Archive finished queues
  • Restore archived queues later

Public panels

Each queue can have a public Discord panel showing whether commissions are open, closed, full, or archived, plus the number of available slots.

Panels update automatically as queue availability and active commission counts change.

04 / From request to completion

🎨 Commission Workflow

🟡

Submitted

A customer has sent a commission request for creator review.

🟢

Accepted

The creator has accepted the request but has not started work yet.

🔵

In Progress

Work on the commission has started.

🟠

Waiting on Customer

Work is paused while the creator waits for information, approval, files, or another response from the customer.

🟣

Ready

The work is ready for final delivery or customer review.

✅

Delivered → Completed

The creator marks the work delivered. The customer can then confirm delivery to complete the commission.

Creator timezone

Price & payment status

Record a price and track unpaid, deposit paid, partially paid, or paid in full. The bot does not process payments.

07 / Common questions

Troubleshooting

I cannot manage commissions

The server owner may have set commission access to Owner Only or Selected Role. Ask the server owner to check /commission access.

The queue says Slots Full

Accepted and active commissions occupy queue slots. Complete or cancel active work, or edit the queue to increase its slot limit.

The panel will not update

Make sure the bot can view the panel channel, read message history, send messages, and embed links.

I removed the bot

Server-associated Creator Commission Manager data is automatically deleted when the bot is removed from that Discord server.

Does the bot handle payments?

No. Price and payment fields are tracking-only. The bot does not process payments or collect card or banking information.

Where should I start?

Run /commission help, then create your first queue with /commission setup.

08 / Project notes

About Creator Commission Manager

Creator Commission Manager was built by Raven as a free Discord utility for creators who want a structured commission workflow without making customers move to another platform.

It is designed around Discord-native queues, buttons, modals, direct messages, and slash commands, with persistent PostgreSQL storage for commission data.
